# Сравнение CPU и GPU

Сравнение выполнено на одном и том же аудиофайле через endpoint `/transcribe`.

## Результаты

| Этап | CPU, сек | GPU, сек | Разница | Ускорение GPU |
|---|---:|---:|---:|---:|
| `diarize` | 11.2339 | 11.3516 | +0.1177 сек | 0.99x |
| `transcribe` | 24.5315 | 14.1538 | -10.3777 сек | 1.73x |
| `merge_transcript_with_speakers` | 0.0000 | 0.0003 | +0.0003 сек | зависит от округления |
| `process_ogg` | 24.8101 | 14.4574 | -10.3527 сек | 1.72x |

## Вывод

- Общее время обработки на GPU уменьшилось с **24.8101 сек** до **14.4574 сек**.
- GPU ускорил обработку примерно в **1.72 раза**.
- Общее ускорение составило **10.3527 сек**, или примерно **41.7%**.
- Основной выигрыш получен на этапе `transcribe`: он стал быстрее примерно в **1.73 раза**.
- `diarize` в этом замере на GPU оказался немного медленнее: на **0.1177 сек** или примерно на **1.0%**.
- Этап объединения сегментов занимает пренебрежимо мало времени по сравнению с распознаванием и диаризацией.

## Команды запуска

CPU:

```bash
make server-cpu
```

GPU:

```bash
make server-gpu
```

Запрос к API:

```bash
curl -X POST http://localhost:8010/transcribe \
  -F "file=@files/test.ogg"
```

## Ограничения сравнения

Это сравнение основано на одном запуске и одном аудиофайле. Для более надёжного результата стоит выполнить несколько запусков в каждом режиме и сравнить среднее и медианное время. На результат также могут влиять прогрев моделей, кэш Hugging Face, загрузка GPU и фоновые процессы.
